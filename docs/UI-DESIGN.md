## 组件规格

### 搜索栏
- 高度：36px
- 左侧放大镜图标（16×16）
- 右侧设置齿轮图标（16×16）
- Placeholder：`"搜索剪贴板历史..."`
- 聚焦时：边框颜色变为强调蓝

### 文字条目卡片
- 内容预览：最多 2 行，溢出显示省略号
- 字体：主字体 13px
- 元数据行：时间戳 + 字符数，小字号 11px，灰色
- 悬停时：背景变深，显示操作按钮（置顶📌、删除🗑）

### 图片条目卡片
- 左侧缩略图：48×48 像素，圆角，object-fit: cover
- 右侧：标签"截图"、尺寸信息
- 悬停时：同文字条目

### 置顶条目
- 左侧 3px 品红色边框条
- 卡片右上角显示 📌 图标
- 固定在"已置顶"分区

### 分区标题
- "📌 已置顶" / "最近记录"
- 右侧显示条目计数
- 字号 14px，加粗
- 置顶分区无内容时折叠隐藏

### 操作按钮
- 尺寸：28×28 像素
- 图标大小：14×14
- 默认隐藏，悬停父卡片时显示
- 平滑过渡动画（opacity 150ms）

### "加载更多"按钮
- 居中显示
- 文字：`"加载更多 (剩余 N 条)"`
- 点击后追加 20 条到列表

### 状态栏
- 底部固定
- 文字：`"{N} 条记录 · 保存期限: {D}天"`
- 小字号 11px，灰色
- 上方有分割线

## 状态设计

### 空状态（无历史记录）
- 居中显示大号剪贴板图标（CSS 绘制，48×48）
- 标题：`"暂无剪贴板历史"`
- 副标题：`"开始复制文字或截图，内容将自动出现在这里"`
- 搜索栏仍然可见

### 搜索无结果
- 居中显示搜索图标
- 标题：`"未找到 '{关键词}' 的相关结果"`
- 副标题：`"试试其他关键词"`

### 加载状态
- 骨架屏：3-5 个灰色动画条，模拟卡片外形
- 使用 CSS animation（shimmer 效果）

### 错误状态
- 顶部横幅：红色/橙色背景
- 显示错误信息和"重试"按钮
- 3 秒后自动消失

## 动画

| 动画 | 属性 | 时长 | 缓动 |
|------|------|------|------|
| 卡片悬停 | background-color | 150ms | ease |
| 按钮出现 | opacity | 150ms | ease |
| 复制反馈 | opacity + transform | 300ms | ease-out |
| 设置面板滑入 | transform translateX | 250ms | ease-out |
| 骨架屏闪烁 | background-position | 1.5s | ease-in-out (infinite) |
| 卡片新增 | opacity + max-height | 300ms | ease-out |

| `Enter` | 复制选中条目 |
