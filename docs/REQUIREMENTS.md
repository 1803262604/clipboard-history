# 需求规格说明书

## 项目概述

**项目名称**：Clipboard History（剪贴板历史管理工具）

**目标平台**：Windows 11

**用户画像**：非技术用户，需要简单直观的剪贴板管理工具

**核心价值**：自动记录剪贴板历史，随时回溯和复用复制过的内容

---

## 功能需求

### F1 - 内容自动记录
| 属性 | 说明 |
|------|------|
| 优先级 | P0（核心） |
| 描述 | 自动监听系统剪贴板，记录用户复制的内容 |
| 支持格式 | 文字（纯文本）、图片（含截图） |
| 触发方式 | 自动，无需用户手动操作 |

### F2 - 内容展示
| 属性 | 说明 |
|------|------|
| 优先级 | P0（核心） |
| 描述 | 以时间降序展示历史记录 |
| 文字展示 | 显示内容预览（最多2行），超出截断显示省略号 |
| 图片展示 | 显示缩略图，标注尺寸和类型 |
| 置顶展示 | 已置顶内容固定在列表顶部，有视觉区分 |
| 分页 | 每次加载20条，支持"加载更多" |

### F3 - 置顶功能
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 用户可将重要内容置顶 |
| 行为 | 置顶项固定在列表顶部，不受过期清理影响 |
| 操作 | 点击置顶按钮切换置顶/取消置顶 |

### F4 - 删除功能
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 用户可手动删除不需要的记录 |
| 操作 | 点击删除按钮，删除前无需确认（可撤销考虑中） |

### F5 - 搜索功能
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 通过关键词搜索历史内容 |
| 支持语言 | 中文、英文 |
| 搜索范围 | 文字内容全文搜索 |
| 搜索行为 | 实时过滤，输入即搜，300ms防抖 |
| 结果展示 | 关键词高亮显示 |

### F6 - 存储期限设置
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 用户可设定历史记录的保存天数 |
| 默认值 | 30天 |
| 范围 | 1-90天 |
| 行为 | 过期且未置顶的内容自动删除 |
| 清理频率 | 应用启动时 + 每小时一次 |

### F7 - 后台运行
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 应用开机自启，后台静默运行 |
| 系统托盘 | 显示托盘图标，右键菜单可操作 |
| 窗口行为 | 关闭按钮最小化到托盘，不退出应用 |

### F8 - 全局快捷键
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 通过全局快捷键唤出/隐藏主窗口 |
| 默认快捷键 | Ctrl+Shift+V |
| 可自定义 | 是（在设置中修改） |

### F9 - 设置面板
| 属性 | 说明 |
|------|------|
| 优先级 | P2（一般） |
| 描述 | 集中管理应用设置 |
| 设置项 | 保存期限、最大条目数、快捷键、主题、开机自启、窗口置顶 |

### F10 - 内容类型筛选
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 在全部、文字、图片三种视图间快速切换 |
| 排序 | 各视图均保持置顶优先、最近复制时间倒序 |
| 搜索 | 关键词搜索仅作用于文字；图片视图按时间浏览 |

### F11 - 截图库批量管理
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 图片视图支持进入管理模式并多选图片 |
| 排布 | 可在列表和响应式缩略图网格间切换，选择持久化保存 |
| 批量操作 | 全选已加载图片、批量删除、批量复制为文件 |
| 删除行为 | 删除数据库记录时同步删除对应 PNG 文件 |

### F12 - 图片复制为文件
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 将历史图片以 Windows 文件对象写入剪贴板 |
| 使用方式 | 复制后可在资源管理器、桌面或支持文件粘贴的应用中直接粘贴 `.png` 文件 |
| 多选 | 支持一次复制多张图片文件 |

### F13 - 图片文字识别并复制
| 属性 | 说明 |
|------|------|
| 优先级 | P1（重要） |
| 描述 | 对用户主动选择的单张历史图片执行文字识别 |
| 语言 | 简体中文 + 英文 |
| 输出 | 识别成功后直接写入系统剪贴板 |
| 隐私 | 完全本地离线处理，不上传图片 |
| 范围限制 | 不保存识别结果，不建立索引，不支持搜索图片文字 |

---

## 非功能需求

| 需求 | 标准 |
|------|------|
| 性能 | 1000条记录内搜索响应 < 100ms |
| 内存 | 长时间运行内存 < 150MB |
| 存储 | 本地存储，不上传任何数据 |
| 可靠性 | 异常退出不损坏数据库 |
| 可用性 | 安装即用，无需额外配置 |

---

## 不做的事（v1.0 范围外）

- 云端同步
- 多设备协同
- 剪贴板内容编辑
- 分类/标签管理
- 隐私过滤（白名单/黑名单应用）
- 导出/导入功能
- 富文本格式保留（RTF/HTML）
- 文件复制记录（不捕获用户复制的文件；历史图片复制为文件属于输出能力）
